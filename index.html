I need more than a single Big Box. Can deliveries be staggered?

Yes. As you fill one or more boxes, Big Box can return to pick them up while also delivering additional ones if needed.

What size is the Big Box?

Each Big Box measures 8' x 5' x 7' (L x W x H exterior) and typically holds one room of contents. If you need more space, multiple Big Boxes can be delivered.
